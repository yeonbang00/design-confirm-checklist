피그마 MCP 연동 (레이아웃 좌표 직접 수신) 정확도 개선 검토
지금 3번(타이포·정렬·여백·명도대비) 판정은 완성된 배너 이미지에서 클로바 OCR로 텍스트 위치를 픽셀 좌표로 "측정"하는 방식입니다. 피그마 MCP를 연결하면 디자이너가 작업한 원본 파일에서 레이어 트리와 실제 x/y 좌표, spacing 값을 그대로 받아올 수 있어서, 완성된 이미지에서 추론하는 대신 디자인 파일에 실제로 기록된 값을 곧바로 대조할 수 있게 됩니다. 정렬·여백 외에도 활용 범위가 넓습니다 — 텍스트 레이어의 실제 폰트명·크기·굵기를 그대로 읽어 3번의 "폰트 2종 이내" 기준을 눈대중이 아니라 정확히 셀 수 있고, 5번(컬러 일관성)도 캔버스 픽셀을 샘플링하는 근사식(redmean) 대신 레이어의 실제 fill 색상값을 바로 대조할 수 있습니다. 로고 레이어의 scale-x/scale-y 차이를 읽으면 16번(로고 사용 규정)의 비율 왜곡도 육안 판단 없이 수치로 잡아낼 수 있고, 파일 최종 수정 시각과 내보낸 이미지를 대조하면 "파일은 고쳤는데 내보내기를 깜빡한" 실무 사고도 감지할 수 있습니다.
왜 아직 안 했나: 3번 항목에서 반복적으로 나오는 오탐(스트록·그림자가 있는 텍스트를 정렬 오차로 오인하거나, 캔버스 중앙정렬을 좌우정렬 규칙으로 잘못 적용하는 경우 등)의 근본 원인이 결국 "이미지에서 좌표를 추론해야 한다"는 점에 있어서, 이 연동이 붙으면 구조적으로 해결될 가능성이 있습니다. 다만 모든 배너가 피그마로 작업되는 건 아니라서(포토샵·일러스트레이터로 작업하는 경우도 많음), 피그마 원본이 있을 때만 보강 데이터로 쓰는 방식으로 설계해야 합니다.

지금 브리프헬퍼 무드보드는 gpt-image-2로 생성하는데, 힉스필드는 제품 사진(product photography)에 특화된 모델을 따로 제공해서 실사 합성 퀄리티가 더 나을 가능성이 있습니다. UGC(사용자 제작 콘텐츠) 스타일 참고 이미지·영상 생성도 지원해서 요즘 광고 트렌드에 맞는 참고 소재를 제안할 수 있고, 스타일 트랜스퍼로 기존 배너 하나를 다른 시즌·톤으로 빠르게 변형한 참고 시안도 여러 개 뽑아볼 수 있습니다.
왜 아직 안 했나: AdCheck는 AI가 검수·정보 제공까지만 하고 최종 결과물은 디자이너가 만든다는 원칙을 처음부터 지켜왔습니다. 힉스필드로 만든 이미지가 "참고용 무드보드"를 넘어 "그대로 쓰는 완성 소재"로 오인되지 않도록 UI·문구 설계부터 먼저 정리해야 하고, gpt-image-2 대비 실제로 품질이 나은지 직접 비교 검증도 필요합니다.

TinEye API 안내 ↗
개인별 계정 시스템 (Supabase 인증·DB 전환) 우선순위 낮음
지금 로그인은 팀 전체가 비밀번호 하나를 공유하는 방식이고, 데이터도 `_referenceLibrary.js` 같은 일반 JS 파일에 저장돼 있습니다. Supabase 같은 서비스로 전환하면 팀원마다 개별 계정으로 로그인하고, 데이터도 진짜 데이터베이스(Postgres)에 저장해서 사람마다 볼 수 있는 범위를 DB 레벨에서 구분하는 것도 가능해집니다.
왜 아직 안 했나: 지금은 팀 규모가 작아 공유 비밀번호로도 충분히 돌아가고 있습니다. 팀원이 늘거나 사람별 권한 구분·개인화된 히스토리가 실제로 필요해지는 시점에 다시 검토하면 될 항목이라 지금은 우선순위가 낮습니다.
DECLINED
넣지 않기로 한 기능
기술적으로 가능하더라도 도구의 성격상 넣지 않기로 판단한 것들입니다.
매체별 배너 베리에이션 자동 생성 직접 구축 안 함
완성된 대표안(원본 배너)을 매체별 규격(사이즈·세이프존)에 맞춰 AI가 자동으로 리사이즈·재배치해서 여러 버전을 만들어주는 기능. OCR로 텍스트 위치를 읽고 매체 가이드로 목표 규격을 아는 것까지는 지금도 가능하지만, 실제로 카피·로고·색상을 정확히 유지하면서 레이아웃을 재구성하려면 PSD 레이어 편집·AI 배경 아웃페인팅 같은 완전히 다른 차원의 이미지 생성·편집 기능이 필요합니다.
왜 안 하기로 했나: 가장 중요한 이유는, 이미 성숙한 상용 서비스인 ResizeAd조차 스스로 명시한 한계가 뚜렷하다는 점입니다 — 카피 문구 자동 생성 안 됨, 원본 디자인 요소 형태 변경 안 됨, 잘린 피사체 AI 보정 안 됨. 이런 경우를 위해 디자이너가 직접 후보정하는 "프리미엄 서비스"(건당 ₩7,000)를 별도로 운영할 정도로, 전담 팀이 만든 제품도 완전 자동화가 안 되는 영역이라는 뜻입니다.
