업데이트 예정

지금 실제로 배너 분석에 쓰이고 있는 기능과, 앞으로 연결하면 도움이 될 만해서 검토했지만 아직 적용하지 않은 기능을 함께 정리했습니다.

사용 중인 기능
GPT-5.6 Sol (OpenAI) 사용 중
배너 이미지를 보고 19개 항목 전체를 판정하는 메인 분석 엔진입니다. 구도·색감·합성 리얼리티·AI 생성 특유의 아티팩트 등 시각적으로 판단해야 하는 부분을 전담합니다.
네이버 클로바 OCR 사용 중
이미지 속 텍스트 위치를 픽셀 좌표로 직접 측정해서, 3번(타이포·정렬)의 정렬 오차와 10번(매체 최적화)의 세이프존 침범량을 AI의 시각 판단이 아닌 실제 수치로 대조합니다.
아직 적용하지 않은 기능
바른한글(나라인포테크) 맞춤법 검사 라이선스 문의 필요
지금 3번(타이포·정렬)에 OCR로 픽셀 위치를 대조하는 것처럼, 4번(정보 정확성) 오탈자 판정도 AI 시각 판단 대신 사전 기반 맞춤법 엔진으로 대조해서 정확도를 높이는 기능입니다.
왜 아직 안 했나: 무료 웹 검사기는 비상업 용도로만 제공되고, 상업적으로 쓰려면 나라인포테크에 별도 API 라이선스를 문의해서 가격·조건을 확인해야 합니다.
구매 문의 페이지 (nara-speller.co.kr) ↗
이미지 유사도·표절 검색 (TinEye API) 비용 발생
스톡 이미지를 무단으로 쓰지 않았는지, 경쟁사나 다른 브랜드 소재와 지나치게 비슷하지 않은지 자동으로 역검색해서 확인하는 기능입니다.
왜 아직 안 했나: 상업용 API가 월 $200(5,000건)부터 시작해서, 배너를 분석할 때마다 매번 돌리기보다는 필요할 때만 선택적으로 켜는 방식으로 붙이는 게 나을지 검토 중입니다.
TinEye API 안내 ↗
로고 감지 (Google Cloud Vision Logo Detection) 실효성 검토 중
18번(로고 사용 규정) 판정 시 이미지 안에 로고가 실제로 있는지, 어디에 있는지를 AI 판단과 별개로 자동 감지해서 보강하는 기능입니다.
왜 아직 안 했나: 이 기능은 이미 잘 알려진 유명 브랜드 로고 위주로 학습돼 있어서, 우리가 다루는 다양한 광고주의 자사 로고는 인식하지 못할 가능성이 높습니다. 지금 상태로는 붙여도 실효성이 낮아 보류 중입니다.
Google Cloud Vision 로고 감지 문서 ↗
WCAG 명도 대비 체크 안전한 적용 방법 검토 중
OCR로 이미 파악한 텍스트 위치의 실제 색상 대비를 계산해서, 5번(컬러 일관성)의 "대비" 판정을 AI의 주관적 판단이 아닌 수치로 뒷받침하는 기능입니다. 외부 API 비용은 들지 않습니다.
왜 아직 안 했나: 이미지를 픽셀 단위로 직접 읽어야 해서 새 이미지 처리 라이브러리를 추가해야 하는데, 지금 작업 환경에서 미리 테스트해볼 방법이 없어 검증 없이 핵심 기능(`/api/analyze`)에 바로 넣기엔 리스크가 있다고 판단했습니다. 안전하게 검증할 방법을 마련한 뒤 적용할 예정입니다.
WCAG 대비 기준 문서 ↗
블러·저품질 감지 신뢰도 검토 중
6·7번(합성 리얼리티, 피사체 보정)에서 잡아내는 AI 생성 특유의 아티팩트(울퉁불퉁한 질감 등)를 이미지 선명도 수치로 보강하려는 아이디어입니다.
왜 아직 안 했나: 배너는 단색 배경이나 그라디언트처럼 원래 "흐릿하게" 측정될 수 있는 영역이 많아서, 단순 선명도 수치만으로는 오탐(진짜 문제가 아닌데 문제로 잡히는 경우)이 많이 날 위험이 있습니다. 더 신뢰할 수 있는 방식을 찾는 중입니다.
