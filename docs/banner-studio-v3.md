# 배너 생성 v3 구현 기록 — 2026-09-15

## 초기 v3 구현 기록 (아래 v3.1에서 변경됨)

링크/상품 담기 → 상품 원문·이미지 확보 → 긴 상세 이미지 분할 → 동일 상품 분류·활용 영역 추출 → 자료 조건에 맞는 R01–R30 후보 → 서로 다른 6종 선택 → 시안별 축으로 레퍼런스 검색·실제 이미지 관찰 → 근거가 연결된 카피 → 완성 배너 생성 → 실제 사진 복원 합성 및 상품/카피 검사 → 다운로드.

원본 활용은 누끼/화보 중 어느 것이 더 좋다는 순위가 아니다. 각 구성에 맞는 자료를 고른다. 원본 활용 여부와 템플릿·그래픽·업종 특화는 별도 속성으로 함께 기록한다. 제형 사진은 실제 상세에서 얻은 사진을 사용한다. 패션 원단을 화장품 제형으로 부르지 않는다. 뷰티에 착장 연속 화보를 배정하지 않는다.

## 혜택과 카피

상품 설명은 최대 12,000자, 페이지 구간은 최대 40개를 유지한다. 원문에서 정확한 발췌가 확인된 혜택만 OFFER 토큰으로 제공한다. 카드/회원 등 조건은 별도 보관해 최종 문구에 함께 전달한다. 계산한 할인율을 표시 할인율로 확정하지 않으며, 2개 구성을 1+1 행사로 바꾸지 않는다.

명시된 가격·수량·혜택 또는 선택한 상세 근거의 숫자만 사용한다. 잘못된 문구는 1회 교정 후 다시 검사한다. 제작 설명이 광고 카피로 들어가는 경우와 같은 가격 중복도 차단한다. 원산지·개봉기한보다 성분·소재·보습·마무리 등 구매 이유를 먼저 기획한다.

## 실자료 검증

- 블루핏: 신세계 링크를 실제 수집했다. 79,000원, 4종, 삼성카드 5% 즉시할인과 결제 조건·기간을 읽었다. 상세 사진과 원단 정보를 확보했다.
- 리얼베리어: 서버 수집은 쇼핑몰 요청 제한으로 실패했다. 브라우저의 실제 공개 상품 화면에서 150ml 2개, 60,000원 → 35,000원, 표시 할인율 41%를 확인했다. 브라우저에서 읽은 자료를 상품 담기 형식의 검증 입력으로 넣었다. 이는 북마클릿 클릭부터의 전체 실행 검증과 구분한다.
- 848×20,591 상세 이미지는 15개 겹침 구간으로 분석했고, 실제 제형 영역 및 성분·사용감·시험 근거를 읽었다.
- 블루핏 6종, 리얼베리어 6종 실제 API 생성에서 CTA·미확인 금액/퍼센트·가격 중복 검사를 통과했다. 리얼베리어 6종은 원본과 제품 동일성 비교도 통과했다. 이후 카피 구매 이유 우선순위를 추가 보완했다.
- 반복 검증에서는 동일 이미지 URL 묶음의 성공한 사진 분석 응답을 로컬에서만 재사용했다. 실제 카피·이미지 생성·OCR·상품 비교는 실제 API를 호출했다. 운영 API에 이 테스트 캐시는 들어가지 않는다.

## 검증 범위와 한계

자동 검사 3개 파일: 출처 발췌, 조건부 혜택, 정확한 숫자, 제형/착장 자료 요건, 100회 v3 조합, 긴 이미지 전체 구간, CTA/가격 중복, 상품 불일치 차단. 기존 조합 회귀 검사도 함께 통과했다.

사진 보존 시안은 실제 사진을 생성 결과에 다시 합성한다. 새 연출 시안은 생성형 편집이므로 라벨·형상·세부 표현을 디자이너가 최종 확인해야 한다. OCR와 시각 비교 통과가 광고 심의 또는 픽셀 단위 동일성을 보증하지는 않는다. Qwen 연동이나 편집 가능한 PSD 레이어 출력은 이번 구현에 포함하지 않는다.

결과 화면의 숨긴 편집 패널이 차지하던 빈 열과 모바일 푸터의 가로 넘침도 정리했다.


## 지속 연계와 카드 혜택 제외

- 카드 즉시할인·청구할인·무이자/할부는 기본 광고 후보에서 제외한다. 수집 원문은 유지하되, 기획 후보·카피 토큰·최종 카피 검증에 같은 정책을 적용한다. 일반 할인·쿠폰·증정·배송 정보는 근거가 확인된 경우 계속 활용한다.
- `criteria-guide.html`이 공통 공개 가이드 원본이다. 분석, 카피 생성, 완성 이미지 생성이 서버에서 동일 파일을 읽는다. 17개 항목의 확인 사항/반려 예시는 유지하고, 단계별 관련 항목의 설명까지 전달한다. 상세 판정의 기존 예외와 브랜드·매체 지침은 유지한다. 가이드 구조가 깨지면 조용히 생략하지 않고 오류를 반환한다.
- 공개 가이드를 수정·배포하면 다음 분석/생성에 적용된다. 생성 전에는 최신 업로드 이미지와 축 태그를 다시 읽는다. 조회 실패 시 오래된 목록만으로 계속하지 않는다. 레퍼런스 추가/재태깅은 배포 없이 다음 생성에 반영된다.
- 카피·이미지의 가이드 버전, 혜택 정책 버전, 레퍼런스 목록·축의 지문과 개수, 선택한 참고 이미지를 제작 기록에 남긴다. 저장된 결과가 과거 버전인지 추적할 수 있다.
- 이것은 최신 자료를 검색하고 공통 규칙을 적용하는 연계다. 분석할 때마다 모델을 자동 재학습하거나 임의 판정을 전체 규칙으로 승격하는 기능은 아니다. 분석에서 확인한 반복 문제를 항목 가이드에 반영하면 생성도 그 기준을 공유한다.
- 추가 검증: 카드 5% 할인과 무료배송을 함께 넣은 실제 카피 API 요청에서 카드 혜택 없이 기본 판매가·무료배송·CTA가 반환됐다. 공개 가이드 지문과 정책 버전도 함께 반환됐다. 최신 뷰티 레퍼런스 231개 조회에서 목록/태그 지문과 `no-store` 응답을 확인했다. 가이드 변경·태그 변경·업로드 추가에 따른 버전 변경 및 목록 조회 실패 차단을 자동 검사했다.
- 최종 리얼베리어 재검증에서 5종은 완료되고 1종은 가격 중복 검사로 차단됐다. 이 결과를 성공으로 표시하지 않는다. OCR 영역 사이 숫자가 붙어 할인율로 오인되는 별도 문제는 수정하고 회귀 검사했다.


## v3.1 — 반복 원본·무드·타이포 연결 수정

사용자가 제공한 블루핏 12개 생성 결과와 패션/화장품 레퍼런스를 비교한 결과, 장식의 종류보다 실제 사진 선택과 광고 정보의 위계가 문제였다. 같은 정면 모델 반복, 큰 무료배송/쿠폰, 잘못된 브랜드 로고, 원본을 생성 결과에 사각형으로 덮는 처리, 실제 레퍼런스를 생성 모델에 전달하지 않는 경로를 함께 수정했다.

현재 경로는 **실제 사진과 원문 → 전체 범위에서 사진 분석 → 무드·포즈·색상·조명·제형 기록 → 활용 영역 추출 → 자료에 맞는 6종과 기본안 → 맞는 레퍼런스 선택 → 실제 배치 관찰 → 카피와 완성 이미지 → 기존 OCR/상품 검사 → 다운로드**다.

- 분석 예산 24장 안에서 앞부분만 자르지 않고 마지막 상세까지 고르게 선택한다. 추출 예산 24개는 각 이미지에 첫 영역을 먼저 배정한 뒤 두 번째·세 번째를 배정한다. 사진 크기도 개수 변경 여부와 무관하게 저장한다.
- 선택한 원본의 사용 횟수·포즈·컬러를 고려해 시안별 사진을 분배한다. 풍부한 패션 자료에는 다른 실제 착장과 컬러 구성이 포함된다. 같은 URL/영역의 중복을 제외한다. 서로 다른 URL의 동일 사진을 시각적으로 중복 검출하는 기능은 아니다.
- 상품명·판매가 기본안은 하나를 보장한다. 나머지도 실제 상품 종류를 메인/서브에서 식별할 수 있어야 한다. 무료배송은 보조 정보이며 쿠폰안의 생성 조건이 아니다. 확인된 일반 할인·쿠폰·증정은 계속 활용하고 카드 할인은 기본 제외한다.
- 실제 상세 문구와 사진의 근거를 카피에 전달한다. 레퍼런스는 사실 근거로 쓰지 않는다. 제품 형태·컬러·제형의 출처를 상품 사진으로 제한한다. 원단 접사는 의자나 행거에 놓을 완제품으로 취급하지 않는다. 생원물 상품은 조리 사진으로 대체하지 않는다.
- 브랜드 무드를 사진에서 관찰하고 기획·레퍼런스 선택·카피·이미지에 함께 전달한다. 차분한 무드에 집게 장난감/극적인 무대를 배정하지 않는다. 사람을 장난감이나 캡슐 속 상품으로 연출하지 않는다. 사진·템플릿·그래픽을 섞되 모든 안에 같은 장식을 강제하지 않는다.
- 선택 레퍼런스의 실제 이미지와 제목/서브 줄 수·상대 글자 크기·텍스트 영역·사진 비중·CTA 형태를 생성 모델에 전달한다. 같은 제목 두 줄의 무의미한 크기 차이, 과도한 자간/세로 변형, 작은 서브, 큰 배송 딱지와 반복 원을 제한한다. 고딕은 기본 선호이며 굵은 고딕만 강제하지 않고 명조 비율도 고정하지 않는다. 로고는 디자이너가 나중에 넣는다.
- 고정 사진창을 준비하고 생성 후 원본을 덮던 경로를 제거했다. 실제 사진을 원본으로 전달하되 이미지 모델이 사진과 타이포를 함께 구성한다. 결과의 픽셀 단위 원본 보존을 보장하지 않는다.
- 변경되지 않은 레퍼런스 관찰은 브라우저에 재사용한다. 이미지 URL·축 태그·수정일·설명 또는 계약 버전이 달라지면 다시 관찰한다. 최신 라이브러리 검색 및 항목 가이드 연계는 유지한다. 실제 디자인 레퍼런스를 이미지 생성 입력에 추가하므로 이미지 입력 비용이 늘 수 있고, 관찰 재사용이 API 이용 전체를 무료로 만드는 것은 아니다.
- 기존 OCR 응답으로 광고 글자의 과도한 크기/작은 서브와 CTA/두 줄 위계 불균형을 보수적으로 검사한다. 패키지 라벨은 별도 취급한다. 이는 사진 미감이나 브랜드 무드가 성공했다는 자동 판정이 아니다.

### 이번 검증

유료 API를 호출하지 않았다. 테스트 6개 파일 통과. 추가 회귀 검사는 풍부한 패션 200회, 뷰티 50회, 원물/밀키트·기타 업종, 뒤쪽 상세 선택·추출 예산 배분, 상품 기본 카피, 과도한 타이포, 무드에 맞는 레퍼런스, 관찰 캐시 무효화, 실제 productPhotos/bannerImage/studioCopy 핸들러를 포함한다. 네트워크를 가로채 상품 사진과 디자인 레퍼런스가 multipart에서 구분되는 것까지 확인했다. 실제 새 이미지의 미감은 이번 검증에 포함하지 않는다.
