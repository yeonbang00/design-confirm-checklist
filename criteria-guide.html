01전략 적합성M3
확인 사항
  • 목적과 타깃 톤이 일치하는가
  • 여러 혜택 포인트가 하나의 오퍼로 수렴하는가
즉시 반려: 서로 다른 오퍼·캠페인이 동시에 경쟁 또는 컨셉 부재
Miller's Law(7±2): 사람이 단기기억에 동시에 담을 수 있는 항목은 보통 7±2개 수준입니다. 배너 하나에 혜택 포인트를 5개, 6개씩 나열하면 하나도 기억에 안 남을 수 있어, 강조 포인트는 1~3개로 압축하는 게 이 항목의 실질적 기준입니다.

기획안(PPT 캡처 또는 pptx)을 함께 업로드하면, 기획안에서 추출한 방향성과 실제 시안이 얼마나 부합하는지까지 함께 대조합니다.

예시로 보면: "최대 70% 할인 + 무료배송 + 신규가입 쿠폰 + 오늘만 특가 + 사은품 증정"처럼 오퍼 5개를 한 배너에 다 욱여넣으면 반려 대상입니다. 이걸 "무료배송, 오늘까지"처럼 캠페인 목적에 맞는 오퍼 하나(또는 핵심 오퍼+보조 오퍼 최대 2개)로 압축했는지가 실제 판정 포인트입니다. 이 항목은 리터칭 강도 같은 시각적 스펙트럼이 아니라 카피·오퍼 구성의 문제라 예시 이미지 대신 이렇게 텍스트 예시로 기준을 잡았습니다.
02위계 및 구조M1M3
확인 사항
  • 헤드라인→비주얼→CTA 흐름인가
  • 우선순위가 크기로 구분되는가
즉시 반려: 모든 요소가 같은 크기로 나열
모듈러 스케일(Major Third=1.25배): 타이포그래피에서 1.25배는 "뚜렷하게 인지되는 최소 크기 단계"로 통용되며, Weber의 법칙(크기 차이는 절대값이 아니라 비율로 지각된다는 심리물리학 법칙)이 이를 뒷받침합니다. OCR로 감지한 텍스트 높이를 계층별로 묶어 가장 큰 계층과 다음 계층의 비율을 계산하고, 1.25배 미만이면서 색상·굵기 구분도 없을 때만 위계가 약하다고 판정합니다.
시선 흐름 패턴: 텍스트 밀도·구도에 따라 사람이 화면을 보는 순서가 어느 정도 정형화돼 있습니다.
Z 패턴
텍스트 적고 이미지 중심 — 좌상단→우상단→좌하단→우하단
F 패턴
텍스트 많음(리뷰·기사형) — 위쪽 넓게, 아래로 갈수록 왼쪽만 짧게
Gutenberg 다이어그램
밀도 낮고 요소가 듬성듬성 — 좌상단(로고)→우하단(CTA) 대각선
구도: 삼분할법(화면 3등분 교차점에 핵심 요소 배치), 황금비(비주얼:텍스트 영역 약 1:1.618), 시각적 균형(무게감 상쇄), 비율 그리드(짧은 변을 N등분해 여백 단위로 — 한 브랜드는 SNS 소재에서 18등분 사용).
배너 카피 3계층 구조(사내 제작가이드 기준): 서브카피(0~2단, 브랜드명·시즌 태그) → 메인카피(1~2단, 핵심 메시지) → 상세설명(1~2단, 조건·부가정보) 순으로 위계를 나눕니다. 카드형 메시지(MMS 등)에서는 메인 텍스트 3줄 이하, 서브 텍스트 1줄 이하를 권장 기준으로 둡니다.
pass
헤드라인이 서브보다 약 2배 커서 위계가 뚜렷함
needsfix
크기 차이가 15%뿐이라 우선순위가 애매
reject
같은 크기의 텍스트가 화려한 배경에 묻혀 우선순위 파악 불가
03타이포·정렬·여백·명도대비M1M3
확인 사항
  • 폰트가 2종 이내로 통일됐는가
  • 위아래로 쌓인 요소끼리 정렬(중앙/좌측/우측)이 정확히 맞는가
  • 로고·헤드라인·CTA처럼 단독 배치된 요소도 캔버스 중앙에서 좌우로 치우치지 않았는가
  • CTA 버튼 안 텍스트가 버튼 안에서 고르게 배치됐는가
  • 강조가 필요한 핵심 정보가 색상·굵기·크기로 구분되는가
  • 텍스트-배경 명도 대비가 충분한가
  • 요소 간 여백·간격이 고르게 정리됐는가
  • 텍스트 줄바꿈이 어색한 위치에서 끊기지 않는가
  • 레이아웃/텍스트가 답답해 보이거나 절대적으로 너무 작아 보이지 않는가
즉시 반려: 텍스트가 그리드 밖으로 밀림, 여백 불균형, 대비 부족, 텍스트 밀도·자간·행간으로 인한 답답함 등
정렬 오차: CLOVA OCR로 각 텍스트 요소의 실제 픽셀 좌표를 측정해 비교합니다. 0px 차이는 통과, 1~2px은 검토 필요, 3px 이상은 반려 — 단 스트록·그림자 효과나 광학적 정렬(뾰족한 자모와 둥근 자모가 섞였을 때의 미세 조정)이 있으면 예외로 봅니다. 캔버스 중앙정렬은 더 여유 있게 좌우 여백 차이 10px까지 허용합니다.
명도 대비 — WCAG 2.1 AA 기준: 일반 텍스트는 4.5:1 미만, 24px 이상 큰 텍스트는 3:1 미만이면 기준 미달로 판정합니다.
텍스트 밀도·절대 크기: OCR 박스 넓이 합계로 전체 이미지 대비 텍스트 밀도(%)와 가장 작은 텍스트 계층의 세로 비율(%)을 참고 수치로 씁니다. 리뷰형·기사형·시험지형·채팅형처럼 텍스트가 많은 게 자연스러운 컨셉은 예외로 처리하고, 제품에 실제로 인쇄되어 촬영된 문구(성분표 등)는 디자이너가 편집할 수 없는 원본이라 모든 밀도·크기 체크에서 제외합니다. 자간·행간으로 인한 로컬 답답함은 OCR로 잴 수 없어 순수 시각 판단으로 확인합니다.
줄간격(행간) 비율: 본문은 폰트 크기의 1.4~1.6배, 헤드라인처럼 큰 텍스트는 1.1~1.3배가 자연스럽습니다 — 실제로 한 브랜드의 배너 헤드라인 스펙도 44pt에 행간 54pt(1.23배), 27pt에 행간 33pt(1.22배)로 이 범위와 일치합니다. 폰트는 2종 이내로 제한하고 굵기 차이로 위계를 주는 것이 여러 폰트를 섞는 것보다 안정적입니다.
Gestalt 원리: 근접성(가까운 요소는 하나의 그룹으로 인식 — 여백·간격 일관성의 근거) · 유사성(같은 역할의 요소는 같은 스타일로 통일해야 한눈에 전달). 강조는 색상·굵기·크기 3요소 중 최소 하나 이상으로 뚜렷이 구분돼야 시선을 끕니다.
타이포그래피 흔한 실수(실제 브랜드 가이드 금지 규정): 텍스트에 윤곽선·효과를 과도하게 적용 · 배경과 낮은 대비 조합 사용 · 헤드라인에 본문용 서체를 사용 · 행간·자간을 과도하게 적용해 가독성을 해침 · 불필요한 줄바꿈으로 시선을 분산시킴 · 가독성이 떨어지는 정렬을 사용.
명도 대비 예시 (WCAG 4.5:1 기준)
pass
7:1 이상 — 또렷하게 읽힘
needsfix
3~4.5:1 — 애매한 경계 구간
reject
3:1 미만 — 거의 안 보임
04정보 정확성M1M2
확인 사항
  • 가격·일정 정보에 오류 없는가
  • 원고와 수치가 일치하는가
즉시 반려: 가격·일정 등 사실관계 오류
2단계 오탈자 검증 절차: 이미지 속 모든 텍스트를 먼저 그대로 옮겨 적게 한 뒤(textTranscript), 그 내용을 다시 처음부터 훑으며 자음·모음 하나 차이 같은 오탈자를 대조합니다.
규칙 기반 맞춤법 검사기(바른한글/PNU WebSpeller): OCR로 읽은 텍스트를 화면 읽기 순서로 이어붙여 규칙 기반 맞춤법 검사기에 보내고, 감지된 오류를 참고 신호로 함께 제공합니다. 배너 카피가 관행적으로 생략하는 종결 문장부호 오탐은 서버에서 미리 걸러냅니다.
최상급·순위 표현 실증 표기(네이버 광고 심사 기준 참고): "최고", "1위" 등 표현이 있는데 근거(수상 내역, 조사기관 등) 표기가 이미지 안 어디에도 없으면 반려로 판정합니다.
표기 컨벤션: 금액은 "3만 원대"(원 표기 시 띄어쓰기 필수), 물결표는 숫자와 붙여쓰기("~70%"), 말줄임표는 광고 카피 특성상 약식(..)도 허용합니다.
05컬러 일관성M1M2
확인 사항
  • 브랜드 컬러를 준수했는가
즉시 반려: 브랜드 컬러 이탈
redmean 색상 거리 공식: 브랜드 가이드 텍스트에서 HEX·RGB 값을 자동 추출하고, 캔버스에서 6×6 그리드로 샘플링한 대표 색상과의 거리를 계산합니다. 정식 CIE ΔE2000이 아닌 경량 근사 공식이라는 한계를 감안해 참고 수치로만 씁니다. 배색 이론·팔레트는 컬러가이드 참고.
06합성 리얼리티M3
확인 사항
  • 톤·질감이 배경과 어울리는가
  • 그림자·반사가 자연스러운가
  • 누끼(컷아웃) 경계가 매끄럽게 처리됐는가 (헤어 잔여배경, 거친 윤곽선 등)
즉시 반려: 합성이 티나거나 이질감이 있음, 누끼 경계에 배경 잔상·거친 윤곽선이 남음
누끼 경계 3종 체크: ① 안티에일리어싱 부족(계단 현상) ② 원래 배경색이 얇게 번져 보이는 할레이션 ③ 헤어 등 세밀한 경계의 배경 잔여물. 사진 합성이 아닌 시안은 이 체크가 자동으로 해당 없음(na) 처리됩니다.

09CTA 및 전환M3
확인 사항
  • CTA가 있다면 문구가 행동을 유도하는가
  • CTA가 있다면 버튼이 눈에 띄는가
즉시 반려: 있는 CTA가 텍스트에 묻히는 등 명백히 눈에 안 띔 (CTA 부재 자체는 매체에 따라 정상일 수 있음)
메타(Meta)처럼 플랫폼이 CTA 버튼을 소재와 별도로 자동으로 붙여주는 매체가 많아, 이미지 안에 CTA가 아예 없는 것은 반려 사유로 보지 않고 참고 제안으로만 남깁니다.
Hick's Law: 선택지가 많아질수록 결정 시간이 늘어납니다(선택지 수에 로그 비례). CTA는 배너 하나에 하나로 압축하는 게 원칙입니다.

Fitts's Law: 타겟(버튼)이 크고 가까울수록 도달·클릭 시간이 짧아집니다. CTA를 작게 만들거나 다른 요소에서 멀리 떨어뜨리면 클릭까지 이어질 확률이 떨어집니다.

그룹 2 · AI 생성 아티팩트
AI로 생성·보정한 이미지 특유의 티가 나는 문제를 잡는 4개 항목입니다. 사진 합성이 아닌 시안에는 대부분 해당 없음(na)으로 처리됩니다.

확인 사항
  • 얼굴(이목구비)이 뒤틀리지 않았는가
  • 손가락·팔다리 비율이 정상인가
  • 자세가 물리적으로 가능한가
즉시 반려: 얼굴·신체 비율이 명백히 어긋남

needsfix

reject
개수·형태가 명백히 왜곡

  • 패턴 경계가 매끄러운가
즉시 반려: 배경이 눈에 띄게 반복됨

reject

그룹 3 · 광고주 전달 전 필수 확인
크리에이티브 품질과 별개로, 매체·브랜드·법적 규정을 지켰는지 반드시 확인해야 하는 4개 항목입니다.
14매체 최적화M1M2
확인 사항
  • 매체 규격(사이즈·용량)에 맞는가
  • 안전 여백 안에 배치됐는가
즉시 반려: 규격·용량 초과 또는 요소 잘림
선택한 매체 가이드(구글 GDN, 카울리, 타겟팅게이츠, TNK 등 실제 공식 자료 기반)의 세이프존 좌표와 OCR 실측 좌표를 대조합니다. OCR 측정 오차를 감안해 10px 이내 침범은 확실한 위반으로 단정하지 않습니다.
15텍스트·로고 렌더링M3
확인 사항
  • 생성된 글자가 정확한가
  • 로고 형태가 원본과 일치하는가
즉시 반려: 글자가 깨지거나 로고가 왜곡됨
pass
글자 형태가 정확함
needsfix

reject
알아볼 수 없이 뭉개짐
16로고 사용 규정M2
확인 사항
  • 로고가 누락되지 않았는가
  • 로고 여백이 다른 요소와 부자연스럽게 붙어 보이지 않는가
  • 색상·비율을 변경하지 않았는가
즉시 반려: 로고 가이드라인 위반
광고주별 브랜드 가이드에 등록된 로고 사용 규정과 대조합니다. 등록된 가이드가 없는 광고주는 일반적인 로고 사용 관행(여백, 최소 크기, 왜곡 금지)을 기준으로 판단합니다.
17법적고지·심의 문구M1M2
확인 사항
  • 필수 고지사항이 포함됐는가
  • 심의 문구 크기가 기준 이상인가
즉시 반려: 법적 고지·심의 문구 누락
대부업법 시행령 기준: 대출·대부업 광고(무담보, 저금리, 즉시대출 등 카피로 판단)는 경고 문구 크기가 시안 내 가장 큰 텍스트의 시각적 1/3 이상이어야 한다는 법적 기준을 적용합니다.
참고한 디자인 시스템
공개된 디자인 시스템 공식 문서에서, 배너처럼 정적인 카드형 콘텐츠에 적용 가능한 원칙만 발췌했습니다. 각 시스템 전체를 따라야 한다는 뜻은 아닙니다.
Material Design: 8dp 기준 그리드, 터치 타겟 48dp, 강조색은 소수만 쓰고 나머지는 중립색으로 절제.
Apple Human Interface Guidelines: 44pt 터치 타겟, 명확한 타이포그래피 위계(Large Title → Title → Headline → Body).
IBM Carbon Design System: 2px 기준 스페이싱 스케일, 명확한 타이포그래피 스케일 테이블을 문서로 공개.
