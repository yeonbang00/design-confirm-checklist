배너 생성 가이드

배너 생성이 무엇을 보고 어떻게 정하는지 적어둔 참고 문서입니다.
읽지 않아도 생성됩니다. 결과가 예상과 다를 때 왜 그런지 찾아보시라고 둔 페이지입니다.

상품 링크를 넣으면 광고 유형 · 텍스트 배치 · 이미지 제작 방식 세 가지를 상품에 맞게 자동으로 조합해 시안 6종을 만듭니다. 여섯 개가 같은 조합이 되지 않도록 섞고, 자료가 없는 방식은 아예 배정하지 않습니다.

숫자는 지어내지 않습니다

할인율·가격·수량은 상품 데이터에서 확인된 값만 씁니다. 카피에는 자리표시자로 들어가고 실제 값은 코드가 채웁니다.

확인되지 않은 할인율이 있으면 혜택직관형·숫자강조형·큰 가격 배치가 후보에서 빠집니다. 신세계 딜 페이지 제목이 "최대 87% OFF"인데 실제 데이터는 128개 전부 20%였던 적이 있어 제목의 숫자는 믿지 않습니다.

어디에 놓을까

카피 길이와 사진에서 비어 있는 자리를 보고 정합니다. 줄바꿈과 글자 크기는 배치가 정해진 뒤 자동으로 맞춰지고, 넘치면 폰트가 줄고 그래도 안 되면 경고가 뜹니다.

이미지 제작 방식

어떻게 만들까

한 번 생성하면 원본 활용 2종 + 새 장면 4종으로 섞입니다. 필요한 자료가 없는 방식은 회색으로 표시했고, 자동으로 배정되지 않습니다.

원본 + 템플릿

상품 사진을 그대로 두고 카피와 배치만 얹는다. 생성 시간이 없고 상품이 변형될 일도 없다.

상품은 바꾸지 않습니다

형태·색·포장·개수는 그대로 두고 배경·조명·카메라 각도만 바꿉니다. 사람이 착용한 사진이면 그 인물을 유지하되, 자세는 장면에 맞게 다시 잡습니다.
