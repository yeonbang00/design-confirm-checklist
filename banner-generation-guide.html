상품 페이지에서 시작합니다

배너 생성에 상품 링크를 입력하세요. 메인 이미지뿐 아니라 상세 사진, 제품 설명, 가격과 혜택 조건을 함께 살펴보고 사용할 자료를 고릅니다.

  1. 자료 수집

    상품 사진과 상세 설명, 판매 조건을 가져옵니다.

  2. 사진·근거 확인

    동일 상품을 골라내고, 상세 이미지 속 사진과 문구를 읽습니다.

    구매 이유와 구도, 무드에 맞춰 사진과 글자를 함께 디자인합니다.

  4. 검사·다운로드

    문구·수치·CTA 등을 검사한 결과를 카드별로 내려받습니다.

링크를 읽지 못하거나 상세 사진이 부족할 때
  1. 배너 생성 화면의 AdCheck 상품 담기를 브라우저 북마크바에 끌어다 놓습니다.
  2. 해당 상품 페이지에서 상세 설명을 펼치고, 사용할 사진과 판매 조건이 보이는지 확인합니다.
  3. 북마크바의 상품 담기를 누릅니다. 페이지가 스크롤되며 사진을 수집하니 완료 안내까지 기다립니다.
  4. 복사된 내용을 AdCheck의 북마클릿으로 복사한 상품 정보 입력칸에 붙여넣고 생성합니다. 복사가 안 됐다면 안내 상자의 내용을 직접 복사합니다.

로그인이나 옵션 선택 뒤에만 보이는 정보, 접힌 상세 영역 등은 수집되지 않을 수 있습니다. 자료가 빠졌다면 해당 영역을 연 뒤 다시 담아주세요.

자료에서 6종의 기획이 만들어지는 과정

사진 분석 결과와 상품 근거를 바탕으로 기획 규칙이 6종을 선택하고, AI가 각 시안의 카피와 디자인을 구체화합니다. 상품마다 쓸 수 있는 사진·정보·브랜드 무드가 다르므로 후보와 조합도 달라집니다.

  1. 사용할 자료와 무드를 정합니다. 메인·상세 사진을 읽어 착장, 옵션, 제형, 음식, 포장을 구분합니다. 동일 상품 여부와 가격·혜택·특징의 근거를 확인하고 사진의 빛·색감·분위기를 정리합니다.
  2. 가능한 구성만 후보에 올립니다. 제품 누끼가 필요한 구성, 실제 제형이 필요한 구성처럼 자료 요건을 적용합니다. 차분한 브랜드에 어울리지 않는 과한 연출도 제한합니다.
  3. 우선 활용할 자료를 배정하고 6종을 고릅니다. 기본안과 업종별 우선 구성을 먼저 고려하고, 광고 유형·표현 계열·시각 장치의 중복과 최근 사용 이력을 반영해 나머지를 선택합니다. 무작위 값도 사용하지만 모든 후보의 확률이 같지는 않습니다.
  4. 각 시안에 사진과 레퍼런스를 연결합니다. 실제 사용할 사진을 배정한 뒤, 프레임·주인공·무드·색감 등이 맞는 레퍼런스를 찾습니다. 메인·서브·CTA의 위치와 줄 수, 크기, 사진 비중, 효과를 읽습니다.
  5. 근거 있는 카피와 완성 이미지를 만듭니다. 기획 의도, 실제 사진, 상품 근거, 레퍼런스 관찰, 항목가이드를 전달합니다. 카피를 확인한 뒤 이미지 모델이 사진과 글자를 함께 디자인하고 결과를 검사합니다.

유형·구성·텍스트 레이아웃은 서로 다른 선택입니다

광고 유형
왜 클릭해야 하는가. 제품 특징, 사용 상황, 구성, 가격, 혜택, 실제 후기 같은 설득 관점입니다.
구성·템플릿
사진과 정보를 어떤 틀로 보여주는가. 전면 화보, 옵션 컬렉션, 상세 확대창, 정보 카드, 그래픽 포스터 등입니다. 현재 공통 구성은 유형·프레임·주인공·시각 장치가 연결된 출발점입니다.
이미지 배정
어떤 원본이 그 기획에 적합한가. 패션은 실제 포즈·컬러를 나누고, 식품은 좋은 대표 음식 사진을 여러 전략에서 재사용할 수 있습니다.
텍스트 레이아웃
무엇을 어느 크기로 어디에 읽히게 하는가. 메인·서브·브랜드·가격·CTA의 위치, 줄 수, 상대 크기, 정렬, 효과를 시안과 레퍼런스에 맞춥니다.

30개 구성안 + 모델 확장 1개가 현재 목록입니다. 다만 ‘14개 광고 유형 × 31개 구성 × 모든 조판’을 전부 곱해 무작위로 뽑지는 않습니다. 공통 기획은 구성에 연결된 유형을 사용하고, 식품은 전략과 표현을 별도로 조합합니다.

6종을 고르는 우선순위와 랜덤 범위

패션·화장품 등 공통 기획은 상품명·가격 기본안을 먼저 포함합니다. 자료가 있으면 패션의 다른 포즈와 컬러, 화장품의 실제 제형, 상세 접사를 우선 고려합니다. 신세계쇼핑의 대상 의류에는 새 모델 착장 확장을 고려하고, 확인된 혜택이 있으면 혜택 구성을 우선 후보로 올립니다.

그다음 그래픽·템플릿·업종 연출 등을 보완합니다. 앞에서 6자리가 채워지면 뒤의 모든 계열을 추가로 보장하지는 않습니다. 후보가 부족하면 만들 수 없는 구성을 억지로 채우지 않습니다.

다양성 점수는 아직 쓰지 않은 유형과 표현 계열을 우대하고, 같은 장치와 최근 완료한 구성의 반복을 줄입니다. 사진 배정도 포즈·컬러·사용 횟수를 고려합니다. 따라서 같은 상품을 다시 생성해도 조합은 달라질 수 있지만, 모든 안이 매번 완전히 바뀌는 것은 아닙니다.

식품은 상품명·가격, 상품 매력, 식사 제안, 포장·구성, 가격·구성, 상품 특징, 구매 혜택, 후기, 품질 근거, 비교, 선물 제안 중 자료가 뒷받침하는 전략을 고릅니다. 이를 음식 전면·상차림·접사·포장과 음식·여백 화보·정보 카드·그래픽 포스터·질감 배경·두 구도·타이포 강조의 10가지 표현과 조합합니다. 같은 전략·표현 쌍은 한 묶음에서 중복하지 않으며, 표현 방식 하나가 6종을 독점하지 않도록 제한합니다.

식품에서 무작위로 달라지는 것은 광고 전략과 보여주는 방식입니다. 대표 음식의 형태·조리 상태·포장을 무작위로 바꾸지는 않습니다. 포장 전략에는 실제 포장이 필요하고, 조리 과정·레시피 안내·한입 보조 컷은 대표 음식으로 배정하지 않습니다.

광고 유형 14종은 어디까지 연결돼 있나요?

배너분석·이미지 레퍼런스의 분류에는 제품단독형, 사용장면형, 혜택직관형, 숫자강조형, 비교형, 리스트형, 질문형, 후기·인용형, 문제제기형, 비포애프터형, 권위형, 시즌이슈형, 이벤트·응모형, 캐릭터·일러스트형이 있습니다.

현재 공통 자동 기획은 이 중 제품·사용 장면·혜택·숫자·리스트·질문 관점을 구성안에 연결해 사용합니다. 식품은 근거가 있는 후기·품질 근거·비교 전략도 선택합니다.

문제제기·비포애프터·시즌이슈·이벤트·캐릭터가 모두 독립 광고 전략으로 자동 추첨되는 것은 아닙니다. 예를 들어 ‘시즌 그래픽’이나 ‘안내 캐릭터’ 구성이 있어도, 그 자체로 기간 한정 행사나 브랜드 캐릭터 사용을 뜻하지 않습니다. 레퍼런스 분류의 범위와 현재 생성 규칙의 범위는 구분해서 봐야 합니다.

문구·글자 효과·버튼·조판은 어떻게 정하나요?
  1. 사진과 메시지에 맞는 공간을 정합니다. 전면·분할·격자·띠·인셋·포스터 등 구성과 사진 속 여백을 기준으로 시선을 설계합니다.
  2. 선택한 레퍼런스의 텍스트 구조를 읽습니다. 메인·서브의 실제 줄 수, 상대 글자 크기, 위치와 정렬, 굵기·외곽선·입체 효과, 사진 비중을 관찰합니다. CTA가 있으면 형태·폭·높이·채움·테두리를 함께 봅니다.
  3. 그 구조에 맞게 카피를 작성합니다. 상품명, 특징, 사용 상황, 확인된 혜택 중 기획에 필요한 내용을 고릅니다. 제목은 보통 1~2줄, 필요하면 최대 3줄로 구성하고, 가격 반복이나 서브 문구 과밀을 피합니다. 서로 다른 사진에 같은 제목이나 CTA를 쓰는 것도 허용합니다.
  4. 항목가이드와 무드로 조정합니다. 한 제목의 줄별 크기를 이유 없이 다르게 하지 않고, 메인과 서브의 위계·대비·여백을 맞춥니다. 고딕을 기본으로 하되 명조 개수를 고정하지 않으며, 효과와 버튼도 브랜드의 차분함·고급스러움·표현 강도에 맞춥니다.
  5. 이미지 모델이 최종 조판합니다. 확정 카피와 실제 사진, 디자인 레퍼런스, 관찰한 배치를 함께 전달합니다. 기존 편집용 CSS 조판 목록에서 하나를 뽑아 글자를 덮는 방식은 현재 기본 생성 경로가 아닙니다.

레퍼런스의 위치·크기는 AI가 관찰한 비율이며 고정 픽셀 좌표가 아닙니다. 버튼은 작은 링크·테두리·채움·띠 등으로 표현할 수 있고, 무료배송은 보조 정보로 다룹니다. 모델이 모든 배치를 정확하게 재현한다고 보장하지는 않습니다.

한 상품에서 조합이 달라지는 예시

다음은 조합을 이해하기 위한 예시이며 고정된 6개 슬롯이 아닙니다. 스트라이프 니트의 착장 사진, 실제 컬러 옵션과 가격이 확보됐다고 가정합니다.

상품을 바로 알리는 안
상품명·가격 + 전면 화보 + 실제 착장 전신 사진 + 사진 여백의 짧은 제목·가격·작은 CTA.
컬러 선택을 돕는 안
구성 안내 + 옵션 컬렉션 + 확인된 컬러별 누끼 + 하나의 제목·짧은 컬러명·공통 CTA.
입었을 때를 보여주는 안
사용 장면 + 포즈 연속 화보 + 상세페이지의 서로 다른 착장 두 컷 + 여백에 간결한 카피와 링크형 CTA.

같은 전면 화보라도 사진·카피·레퍼런스에 따라 제목의 위치와 크기, 사진 비중과 버튼이 달라집니다. 반대로 같은 문구를 유지하고 착장 사진만 바꾸는 것도 유효한 변화입니다.

어떤 자료가 있어야 사용할 수 있나요?
가격·할인·쿠폰
해당 상품에 적용되는 금액, 할인율, 기간과 조건. 참고 배너의 혜택은 가져오지 않으며 카드 결제 할인은 기본 광고에서 제외합니다.
후기·인증·비교
출처가 있는 후기 원문, 인증·시험 자료, 비교 대상과 조건. 사진 두 장만으로 효능이나 전후 변화를 주장하지 않습니다.
컬러·패키지·구성
실제 옵션 사진과 구성 정보. 없는 색상이나 다른 모양의 포장을 새 상품처럼 만들지 않습니다.

업종에 맞게 사진을 활용합니다

좋은 사진의 기준은 쓰임에 따라 달라집니다. 상품이 잘 드러나는 원본을 우선하고, 연출이 필요할 때도 제품의 정체성을 유지합니다.

패션 — 실제 착장과 컬러를 우선

상세페이지의 여러 포즈와 컬러를 배분하고, 같은 모델 사진 하나만 반복하지 않도록 합니다. 실제 누끼가 있으면 컬러 구성, 행거·의자 연출 등에 활용하며, 소재 접사를 완제품처럼 쓰지 않습니다.

브랜드가 차분하고 감성적인 무드라면 그래픽과 타이포도 그 분위기를 따릅니다. 젊은 모델이 있다는 이유로 키치하거나 펑키하게 만들지 않습니다.

신세계쇼핑 의류는 원본 모델을 우선하면서, 옷의 전체 형태를 확인할 수 있으면 한 안을 세련된 30~40대 한국인 여성 모델 착장으로 확장합니다. 원본 얼굴을 노화시키지 않으며, 남성복·아동복은 제외합니다.

화장품 — 같은 제품, 실제 제형과 근거

병·튜브·펌프·라벨·제품 색상을 유지합니다. 상세페이지에 해당 제품의 제형이나 사용 사진이 있으면 함께 활용하고, 다른 제품의 사진이 섞이지 않도록 확인합니다.

제품 특징, 제형, 확인된 효능 근거, 가격·혜택을 자료에 맞춰 나눕니다. 수치나 비교 효과를 만들지 않으며, 그래픽·타이포 효과도 브랜드 무드와 선택한 레퍼런스에 맞춥니다.

식품 — 본제품이 돋보이는 다양한 연출

대표 음식 사진을 유지하면서 전면·접사·상차림·여백·그래픽 등으로 확장합니다. 한입을 든 사진과 레시피 예시는 대표 음식과 구분합니다. 포장·구성을 소개하는 안에는 실제 포장 사진을 배정하고, 포장 사진만 있으면 내용물을 상상해 꺼내지 않습니다.

상품 매력, 식사 제안, 가격·구성, 확인된 혜택·후기·품질 근거 등을 서로 다른 표현과 조합합니다. 패키지형·상차림형 등이 매번 같은 번호로 나오지는 않습니다.

상차림에는 밥·김치 등 소량의 곁들임을 둘 수 있습니다. 본제품의 시선을 빼앗거나 판매 구성·함유재료로 보이지 않게 하며, 본제품의 형태·조리 상태·기존 고명은 유지합니다. 설명만 보고 굽기·양념 붓기 같은 조리 과정을 만들지 않습니다.

그 외 업종 — 확인할 수 있는 특징부터

실제 상품과 사용 장면, 구성, 확인된 기능·혜택을 기준으로 기획합니다. 다른 업종의 연출을 그대로 적용하거나 자료에 없는 성능·효과를 만들지 않습니다. 사용할 정보가 적으면 표현의 범위도 좁아집니다.

항목가이드와 레퍼런스는 이렇게 연결됩니다

항목 가이드는 제작과 검수의 기준이고, 이미지 레퍼런스는 구도와 표현을 고르는 자료입니다. 상품 페이지는 사진과 사실의 근거를 제공합니다.

항목가이드를 생성에 적용하는 방식
공통 기준배너 생성에 반영하는 내용
메시지·위계·정렬무엇을 파는지와 구매 이유가 드러나도록 정리하고, 사진·메인·서브·CTA의 우선순위와 여백을 맞춥니다.
타이포·가독성제목의 줄 수와 크기 관계, 서브 글자 크기, 대비를 고려합니다. 고딕을 기본으로 하되 굵은 고딕만 쓰거나 명조 개수를 고정하지 않습니다.
빛·합성·형태광원, 그림자, 원근과 반사가 어울리도록 지시하고, 실제 상품의 형태와 색을 유지합니다.
CTA·전환행동 문구를 포함하되 작은 링크·테두리 버튼·띠 등 시안에 맞게 표현합니다. 무료배송은 보조 정보로 다룹니다.

배너분석과 생성은 같은 공개 항목가이드를 참고합니다. 다만 생성 후 자동검사가 배너분석의 17개 항목 전체를 대신하지는 않습니다. CTA가 없는 기존 소재의 판정도 매체와 기획 맥락을 따릅니다.

레퍼런스는 유형 이름뿐 아니라 실제 배치를 봅니다

  1. 기획에 맞는 축을 정합니다. 업종과 광고 유형을 바탕으로 프레임, 주인공, 시각 장치, 인물, 무드와 색조를 살펴봅니다.
  2. 시안마다 적합한 소재를 찾습니다. 축과 브랜드 무드가 맞는 레퍼런스를 고르고, 최근 사용한 소재의 반복을 줄입니다.
  3. 이미지 안의 디자인을 읽습니다. 메인·서브의 위치와 줄 수, 상대적인 글자 크기, 사진 비중, 여백, 텍스트 효과, CTA의 모양과 크기를 참고합니다.
  4. 현재 상품에 맞게 다시 구성합니다. 실제 상품 사진과 확정 카피를 사용합니다. 레퍼런스 속 제품·모델·로고·가격·혜택은 복사하지 않습니다.
자료가 쌓이면 어떻게 반영되나요?

새 이미지와 태그는 다음 생성의 레퍼런스 검색에 반영됩니다. 잘못 분류된 업종·유형·구도·색감은 수정할수록 적합한 후보를 찾는 데 도움이 됩니다.

배너분석에서 반복되는 문제는 검토 후 항목가이드에 보완합니다. 반영된 가이드는 이후 분석과 생성에서 함께 참고합니다. 모든 분석 결과가 자동으로 새 규칙이 되거나 모델을 재학습시키지는 않습니다.

새로운 전략이나 제작 방식을 추가하려면 생성 규칙도 함께 보완해야 합니다. 이미 만든 배너는 자료가 바뀌어도 자동 수정되지 않습니다.

완성 이미지를 골라 마무리합니다

기본 결과는 사진과 광고 문구를 함께 디자인한 이미지입니다.

이미지 다운로드
선택한 카드의 완성 배너를 내려받습니다.
텍스트 없는 이미지 다운로드
광고 글자를 지운 이미지를 별도로 만듭니다. 첫 요청에는 추가 생성 비용과 시간이 들며, 복원 과정에서 주변 디테일이 달라질 수 있습니다.

자동검사는 광고 수치·가격 중복·CTA·브랜드 표기와 일부 타이포 문제를 확인합니다. 화장품·식품과 새 모델 착장은 해당 상품의 동일성도 비교합니다. 실패한 카드는 완료된 이미지로 내려받을 수 없습니다.

마지막으로 디자이너가 확인하세요. 상품·옵션의 정확성, 문구와 판매 조건, 브랜드 무드, 합성의 자연스러움과 매체 규격을 확인합니다. 판매처 로고는 후작업으로 넣고, 상품 브랜드명은 읽히는 일반 텍스트로 유지합니다.

완성안을 더 살펴보려면 배너 분석과 매체 가이드를 활용하세요.
